# 📚 College Management System

A modern desktop-based College & Library Management System developed using **C# WinForms** and **SQL Server**. The application helps administrators manage books, students, book issuance, returns, reports, and system settings through a clean and user-friendly interface.

---

## 🚀 Features

### 📖 Book Management

* Add new books
* Update book details
* Delete books
* View all books
* Category-wise book organization
* Rack number management
* Book quantity tracking

### 🎓 Student Management

* Add student records
* Update student information
* Delete students
* View all students
* Enrollment number management
* Student image support

### 📚 Book Issue & Return

* Issue books to students
* Student search functionality
* Book search functionality
* Due date management
* Return book tracking
* Status management (Issued / Returned)
* Duplicate issue prevention
* Stock availability validation

### 📊 Reports Module

* Generate reports
* Filter report data
* Export reports to PDF
* Export reports to Excel
* Print reports
* Professional report layouts

### ⚙️ Settings Module

* Change administrator password
* Database backup
* Database restore
* Application customization

### 🎨 User Interface

* Modern WinForms UI
* Theme support
* Organized dashboard
* Responsive DataGridView design
* Custom message boxes

## ⚡ Installation

1. Clone the repository

```bash
git clone vivaank21/College-Library-System
```

2. Open the solution in Visual Studio

3. Configure SQL Server connection string in:

```text
Database/DBConnection.cs
```

4. Create the required database tables

5. Run the application
